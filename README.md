# Steer'n Roll — Stereoscopic Flow-Sensing for Planktonic Prey Detection

Python code associated with the paper:
"Steer'n Roll: A Stereoscopic Flow-Sensing Strategy for Planktonic 
Prey Detection and Capture", Journal of the Royal Society Interface, 2026.

Authors: T. Redaelli, E. Kanso, C. Eloy
Funded by ERC project C0PEP0D.

## Requirements
Python 3.11
matplotlib
numpy
scipy
pyquaternion
